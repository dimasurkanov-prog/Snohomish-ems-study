# Snohomish EMS Study PWA v2.1

Adds source-reference charts, algorithms, tables, and other visual pages from the uploaded education draft. Midazolam (Versed) now includes the Intranasal Midazolam Dosing Chart directly on the medication page, and protocols with embedded visual reference pages show those visuals in the protocol detail. Tap any visual to open the source page full size.

Also retains v1.5 practical pharmacology notes and v1.3 progressive multiple-choice study modes.

## v2.1 quiz redesign

The former protocol-recognition items were replaced with application-style questions grounded in the uploaded V7 education draft. Each includes fixed, plausible choices, an explanation, and protocol/page attribution. Outside pharmacology notes remain separate and are not used for county-protocol quiz answers.

## v2.1 navigation

The five-tab navigation was simplified to Home, Learn, and Library. Learning modes are nested in Learn; protocols, medications, reference charts, and favorites are nested in Library.

## v2.1 guided learning

Learn now includes guided protocol lessons, guided medication lessons, reveal-based source cards, and a daily quick lesson before the existing quizzes.

## v2.1 back navigation

Active and completed quizzes now have Back to Learn. Guided medication and protocol details have back buttons that return to their respective lesson lists.

## v2.1 visible back controls

Quiz pages now scroll to the top when opened. Lesson modals reset their internal scroll position whenever content changes. Back controls are sticky and remain visible.
